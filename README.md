# 환율 데일리 브리핑 (Daily FX Briefing)

매일 아침 **9시(KST)**에 환율 관련 브리핑을 자동으로 생성·전송하는 스케줄 작업 설정입니다.

## 무엇을 하나요?

매일 09:00 KST에 새 Claude Code 세션이 자동 실행되어 웹을 조사한 뒤 다음 3개 섹션의 브리핑을 만들고, **푸시 + 이메일**로 전달합니다.

1. **📊 전날 환율 이슈 요약** — 전 영업일 원/달러 종가·등락, 주요 통화(엔·유로·위안·DXY) 동향, 환율을 움직인 핵심 요인.
2. **🔗 꼭 읽어야 할 기사** — 반드시 읽어야 할 중요 기사 3~5개를 클릭 가능한 링크 + 한 줄 이유와 함께.
3. **📅 오늘의 주요 환율 이벤트** — 오늘 예정된 경제지표·FOMC/금통위·연설 등을 한국시간과 함께, 원/달러 영향 코멘트 포함.

## 스케줄 설정

| 항목 | 값 |
|------|-----|
| 트리거 ID | `trig_01U7MTzq3M7PqonyzFAQdpR1` |
| Cron (UTC) | `0 0 * * *` = 매일 00:00 UTC = **09:00 KST** |
| 발화 방식 | 매 실행 시 새 세션 생성 (`create_new_session_on_fire`) |
| 알림 | 푸시 ✅ / 이메일 ✅ |
| 언어 | 한국어 |
| 통화 초점 | 원/달러 중심, 엔·유로·위안·DXY 포함 |

> 스케줄은 Claude Code Remote 트리거로 관리됩니다. 시간·통화·언어·알림 채널 변경은
> 트리거를 수정하면 됩니다.
